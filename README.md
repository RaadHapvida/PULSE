# PULSE
"Olá! Sou PULSE, um sistema inteligente de triagem para Pronto Socorro.  Meu trabalho é simples: quando um paciente chega, você digita nome, data de nascimento e queixa. Em segundos, identifico se é protocolo urgente (sepse, AVC, dor torácica), vulnerável (idoso sozinho, psiquiátrico, risco suicida) ou prioritário (gestante, deficiente, 80+).
